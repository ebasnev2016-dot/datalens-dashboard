# DataLens Dashboard - Анализ книжных магазинов

##  Описание проекта
Дашборд для анализа продаж книжных магазинов на основе данных из Google Sheets. 
Визуализирует ключевые метрики: продажи, клиентскую активность, популярность товаров и географическое распределение.

##  Основные дашборды

### 1. Общие показатели
- Количество заказов
- Общая сумма продаж
- Количество клиентов
- Количество позиций в ассортименте

### 2. Анализ продаж
- Сумма продаж по магазинам
- Сумма скидок по магазинам
- Средний чек по магазинам
- Динамика заказов по часам и месяцам

### 3. Демографический анализ
- Распределение по полу
- Возрастная структура клиентов
- Предпочтения по товарам (мужчины/женщины)

### 4. Типы оплаты
- Распределение по типам оплаты
- Динамика заказов по типам оплаты

### 5. Географический анализ
- Карта магазинов Санкт-Петербурга
- Ключевые показатели по локациям

##  Используемые технологии
- **Yandex DataLens** - визуализация данных
- **Google Sheets** - источник данных
- **JSON** - формат хранения дашборда

## Как использовать

### Импорт в DataLens
1. Скачайте файл `dashboard.csv`
2. Загрузите его в Google Sheets
3. Подключите к DataLens
4. Импортируйте `bookstore_dashboard.json`


### Требования к данным
Дашборд работает с данными книжных магазинов со следующими полями:
- Время/Дата доставки
- Магазин
- Id заявки/клиента
- Сумма заказа/скидки
- Тип оплаты
- Пол/Возраст клиента
- Категория и наименование продукта
- Координаты
